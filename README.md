# نرم‌افزار برنامه‌ریزی سینا — پروژهٔ APK

ساخت APK در GitHub به‌صورت خودکار انجام می‌شود (نیازی به Android Studio نیست).

1. در github.com یک حساب رایگان بساز و یک مخزن (Repository) جدید بساز.
2. همهٔ محتویات این پوشه را (شامل پوشهٔ مخفی `.github`) در مخزن آپلود کن.
3. به تب **Actions** برو؛ ساخت خودکار شروع می‌شود (حدود ۵ تا ۱۰ دقیقه). اگر شروع نشد، «Build APK» ← «Run workflow».
4. وقتی تمام شد (تیک سبز)، روی آن اجرا کلیک کن و از بخش **Artifacts** فایل `sina-planner-apk` را دانلود کن.
5. zip را باز کن و `app-debug.apk` را روی گوشی نصب کن (اجازهٔ «نصب از منابع ناشناس» را بده).
6. بعد از نصب: اجازهٔ اعلان را بپذیر، سپس ویجت را از لیست ویجت‌های گوشی (نگه‌داشتن روی صفحهٔ اصلی ← Widgets) اضافه کن.

ساعت اعلان‌ها از دکمهٔ ⚙️ داخل برنامه قابل تنظیم است.
